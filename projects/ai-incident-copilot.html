AI-Incident-Copilot

Operational assistance for incident investigation and root-cause analysis.

01 / PROBLEM

Why this engineering pattern matters

Incident response requires engineers to correlate signals under time pressure. AI can organize evidence and suggest hypotheses, but responders should validate findings before production action.

02 / SYSTEM FLOW

Architecture at a glance

Metrics + logs + alerts → signal correlation → AI-assisted hypotheses → remediation suggestions → human validation

03 / PRODUCTION CONSIDERATIONS

SECURITY

Controlled access

Apply least privilege, protect credentials, scan artifacts and require appropriate review gates.

RELIABILITY

Safe operations

Plan for failure, observable runtime behavior, rollback or recovery and tested runbooks.

MAINTAINABILITY

Repeatable workflows

Keep configuration versioned, modular and documented.

ARCHITECTURE / SOURCE-BACKED

Local incident RAG architecture

The source README documents a local Streamlit UI, FastAPI diagnosis endpoint, LangChain agent, Ollama-hosted Llama 3.1, and Oracle Database 26ai vector search over incidents, runbooks, and service ownership.

RETRIEVAL

Hybrid context

Vector similarity is combined with structured metadata to find related incidents and associated runbooks.

INFERENCE

Local model runtime

Ollama serves Llama locally; the agent uses tools to retrieve evidence rather than relying on public web search.

OPERATIONS

Cited recommendations

Diagnosis output should be treated as decision support. Responders verify citations and telemetry before taking action.

Reproduce the project checks

Follow the README from the repository root. The project documents pytest unit/smoke tests and a separate integration marker for tests requiring Oracle and Ollama.

git clone https://github.com/DataOpsInnovator/ai-incident-copilot.git
cd ai-incident-copilot
pytest
pytest -m integration

The integration suite requires the database and Ollama to be running. For the full local setup, follow the README's database, model, seed, API, and Streamlit steps. Record the commit SHA, Python version, test output and exit code; no passing test result is asserted by this portfolio page.
